    Wiring it to a real Mac

    The map runs on two independent feeds. The agent's own reports are useful but can't be trusted alone, so the OS feed is the ground truth and the gap between them is the signal.

    What the agent says

    A Claude Code hook posts every tool call to your collector. OpenTelemetry export adds model requests. For Copilot, tail the VS Code agent logs.

    // ~/.claude/settings.json
"hooks": {
  "PostToolUse": [{
    "matcher": "*",
    "hooks": [{ "type": "command",
      "command": "fenceline emit" }]
  }]
}

    What the Mac sees

    eslogger streams Endpoint Security events as JSON (needs root and Full Disk Access). Keep only the agent's process tree. For network, a Network Extension filter attributes each connection to a PID, the way LuLu does.

    sudo eslogger exec open write create \
  | fenceline ingest \
      --root-pid "$(pgrep -nx claude)"

    The diff

    An OS event from a descendant of the agent's PID with no matching report within two seconds becomes a ghost on the map. If it also crosses the fence, it's raised as an incident.

    seen  open ~/.aws/credentials
      pid 5203 (python3) ← 4821
said  —
=>    GHOST + BREACH
      rule: secret read outside
            workspace

    Event format

    Send one JSON object per line, over a WebSocket or in a .jsonl file. Each object is one action, already matched up. Set said to null when the Mac saw something the agent never reported, and the map draws a ghost. Leave out verdict and the page applies its own rules.

    {
  "ts": "2026-10-08T22:43:12+01:00",
  "agent": "claude-code",
  "title": "Read AWS credentials",
  "zone": "vault",
  "target": "~/.aws/credentials",
  "said": null,
  "seen": [
    { "source": "es",
      "text": "open ~/.aws/credentials pid 5203" }
  ],
  "verdict": "breach",
  "rule": "Secret read outside the workspace"
}
    FieldValuesNotes
    agentclaude-code, copilotRequired. Picks the character.
    zonefence, net, tools, vaultRequired. Workspace, internet, a CLI tool, or anywhere else on the Mac.
    targetpath, domain or toolRequired. Domains are grouped by site; new paths and tools take over the least-used plot.
    saidobject, string or null{source, text} from the agent. Null means unreported.
    seenarray{source, text} OS observations. Source shows as the line label.
    verdictok, warn, breachOptional. Otherwise: unreported outside the fence is a breach, the rest of the Mac is a warning, unlisted domains are new.
    title, rule, tsstringsOptional. Row heading, reason shown under it, ISO time.
