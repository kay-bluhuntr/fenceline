    How the map reads events

    Each event pairs what the agent reported with what the operating system observed. The agent's own reports are useful but can't be trusted alone, so the gap between the two is the signal.

    Reported and observed

    The agent said it ran a command and the OS saw the same thing. The character walks out, does the job and comes back.

    "said": { "source": "hook",
  "text": "Bash \"npm test\"" },
"seen": [{ "source": "es",
  "text": "exec npm pid 5120" }]

    Outside the fence

    Anything beyond the workspace is drawn where it happened: a building for each website, a hut for each tool, a vault for sensitive folders.

    "zone": "net",
"target": "docs.stripe.com",
"verdict": "warn",
"rule": "First visit to this domain"

    Seen, never reported

    When said is null, a ghost walks the route and cracks the fence on the way out. Outside the workspace, that raises an incident.

    "zone": "vault",
"target": "~/.aws/credentials",
"said": null,
=> GHOST + BREACH

    Event format

    Send one JSON object per line, over a WebSocket or in a .jsonl file. Each object is one action, already matched up. Set said to null when the Mac saw something the agent never reported, and the map draws a ghost. Leave out verdict and the page applies its own rules.

    {
  "ts": "2026-10-08T22:43:12+01:00",
  "agent": "claude-code",
  "title": "Read AWS credentials",
  "zone": "vault",
  "target": "~/.aws/credentials",
  "said": null,
  "seen": [
    { "source": "es",
      "text": "open ~/.aws/credentials pid 5203" }
  ],
  "verdict": "breach",
  "rule": "Secret read outside the workspace"
}
    FieldValuesNotes
    agentclaude-code, copilotRequired. Picks the character.
    zonefence, net, tools, vaultRequired. Workspace, internet, a CLI tool, or anywhere else on the Mac.
    targetpath, domain or toolRequired. Domains are grouped by site; new paths and tools take over the least-used plot.
    saidobject, string or null{source, text} from the agent. Null means unreported.
    seenarray{source, text} OS observations. Source shows as the line label.
    verdictok, warn, breachOptional. Otherwise: an unreported internet connection or read of a credential file is a breach, other unreported actions are a check, unlisted domains are new.
    workspacestringOptional. Relabels the fenced area, such as ~/code/payments-api.
    title, rule, tsstringsOptional. Row heading, reason shown under it, ISO time.
